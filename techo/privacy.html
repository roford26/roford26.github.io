アカウント手帳 プライバシーポリシー

「アカウント手帳」（以下「このアプリ」）は、Roford（以下「運営者」）が出している Android のアプリです。この文は、このアプリが情報をどう扱うかを説明するものです。

あなたが書いた内容は、どこにも送りません。
広告を表示するために、広告のしくみが端末の情報を Google に送ります。

1. このアプリが保存するもの

次のものを、このアプリを入れたスマホの中だけに保存します。

  • 一覧に書いた会社の名前とジャンル（自分で書いたものをふくむ）
  • 会社ごとの「登録しているもの」の印（氏名・住所などの種類だけ。中身は保存しません）
  • やりたいことに並べた会社、「済」にした日時
  • 「死後の取り扱い」で選んだこと、最後に直した日、1枚に載せる会社
  • 「パスワードの保管場所」に書いたことと、会社ごとの保管場所の印
  • 「起きたことの記録」に書いたこと（日付、選んだできごと、金額、メモ）
  • 「変更したいこと」に書いたこと（選んだこと、自分で書いたこと、済にした日時）
  • 「ほかの人の分も書く」を入れたときの、会社ごとの「だれの」の札（自分で書いた呼び名）
  • 発表のあった会社の一覧をどこまで見たか
  • はじめに選んだ「使う目的」、きせかえ、前回書き出した日

2. 広告

  • 一覧の画面のいちばん上に、広告を1つ表示します。広告の表示には、Google LLC（以下「Google」）の「AdMob」を使います。アプリに入っている広告のしくみの名前は「Google Mobile Ads SDK」です。
  • 広告のしくみは、次の情報を自動で集めて Google に送ります。広告の表示、分析、不正の防止に使われます。
    • IP アドレス（おおよその地域の推定に使われることがあります）
    • アプリの中の操作（起動、タップなど）
    • アプリの動きの記録（起動にかかる時間、止まった割合、電池の使用量など）
    • 端末やアカウントを見分ける番号（広告 ID、アプリセット ID、端末でログインしているアカウントに関連する番号）
  • このアプリは、その人に合わせた広告（パーソナライズ広告）を表示します。Google は、広告 ID などを手がかりに、ほかのアプリやサイトの利用のようすもふまえて、表示する広告を選ぶことがあります。
  • 広告 ID は、Android の「設定」にある広告の項目で、リセットまたは削除できます。
  • 「このアプリが保存するもの」に書いたもの（会社の名前、印、選んだこと、起きたことの記録、札など）は、Google にも、広告を出す会社にも送りません。
  • Google に送られた情報の扱いと、持っておく期間は、Google の決まりにしたがいます。くわしくは、次のページをご覧ください。
    • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
    • Google プライバシー ポリシー

3. このウェブページについて

このプライバシーポリシーのページは、GitHub, Inc.（以下「GitHub」）のサービス「GitHub Pages」に置いています。インターネットのしくみ上、このページを開くと、IP アドレスなど通信に付いてくる情報が GitHub に伝わります。GitHub は、セキュリティのために、アクセスした人の IP アドレスを記録して保存すると公表しています。この情報の扱いと、持っておく期間は、GitHub の決まりにしたがいます。（GitHub General Privacy Statement（英語のページ））

4. 運営者が集めないもの

  • 運営者が、利用状況の解析や不具合の自動報告のしくみを別に入れることはありません。
  • 運営者は、利用者の情報を売りません。
  • アプリを配っているストア（Google Play）が集める情報は、ストアの決まりにしたがいます。

5. スマホの機能の利用

連絡先・位置情報・カメラ・マイク・写真は使いません。「ファイルに書き出す」「ファイルから戻す」のときだけ、利用者が選んだ場所のファイルを読み書きします。

6. 安全に扱うための手順

  • 記録は、スマホの中の、このアプリ専用の場所に保存します。
  • 記録は、Android の自動バックアップ（クラウドへの自動の写し）の対象から外しています。
  • 運営者は、利用者の記録を受け取らず、持ちません。運営者のところから記録がもれることはありません。
  • 広告のしくみが集めた情報は、暗号化（TLS）して Google に送られます。
  • お問い合わせのメールは、2段階認証をかけたメールアカウントで受け取り、運営者だけが読みます。
  • このアプリには、画面のロックや、記録を暗号化するしくみは入れていません。スマホの画面ロックを使ってください。

7. 書き出したファイル

書き出したファイルは、利用者が選んだ場所に保存されます。そのあとの保管と受けわたしは、利用者が管理します。

8. 情報を持っておく期間と、消し方

  • スマホの中の記録：利用者が消すまで残ります。「設定」の「このアプリのデータをすべて消す」を押すか、アプリを削除すると消えます。運営者は記録を持っていないので、運営者に連絡する必要はありません。
  • お問い合わせのメール：返事が済んでから1年で消します。消してほしいと連絡をいただいたときは、それより前に消します。
  • Google と GitHub に伝わった情報：それぞれの会社の決まりにしたがいます。

9. お問い合わせで受け取る情報

  • お問い合わせのメールを受け取ったときは、メールアドレス、メールに表示される名前、メールの内容を、返事をするためだけに使います。
  • メールは、Google のメールサービス「Gmail」で受け取り、保管します。
  • 本人の同意なく、ほかの人に渡すことはありません（法令にもとづく場合をのぞきます）。
  • 自分のメールについて、内容の確認・訂正・削除を希望するときは、下のお問い合わせ先に連絡してください。

10. この方針の変更

この方針を変えたときは、このアプリの中と、このページに、新しい方針を表示します。
